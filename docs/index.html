Folio and Fiken.
Tools for your agent.

Typed clients, MCP servers and CLIs for Norwegian banking and accounting. The model reads the receipt and proposes the booking. The adapters expose the APIs.

Source on GitHubSecurity

Two packages

@bruchris/folio-mcp provides accounts, transactions, events, receipt bytes, categories and payment drafts.

@bruchris/fiken-mcp provides companies, accounts, contacts, purchases and purchase attachments.

Install after the first npm release

Version 0.1.0 is prepared; npm publication is pending. Requires Node 22.14+.

npx -y @bruchris/folio-mcp
npx -y @bruchris/fiken-mcp

Use your own vendor credentials in your client environment. Never paste keys into a public issue. Read the package documentation for OAuth setup and vendor restrictions.

Approval stays explicit

MCP writes preview until confirmed. CLI writes require --confirm. Folio payments remain drafts and require approval in Folio. Booking payment dates and NOK amounts come from the Folio transaction.
