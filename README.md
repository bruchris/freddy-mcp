# Folio and Fiken MCP repositories

This combined repository has been superseded. Each MCP now has its own public source repository, documentation and release workflow:

- [bruchris/folio-mcp](https://github.com/bruchris/folio-mcp) — @bruchris/folio-mcp, the Folio client, MCP server and CLI. [Documentation](https://bruchris.github.io/folio-mcp/).
- [bruchris/fiken-mcp](https://github.com/bruchris/fiken-mcp) — @bruchris/fiken-mcp, the Fiken client, MCP server and CLI. [Documentation](https://bruchris.github.io/fiken-mcp/).

Use those repositories for development, issues and future releases. This repository preserves the earlier combined-source history and will receive no further releases. Npm publication is disabled here. Freddy application source remains private and is not part of any of these public repositories.

The retained MCP source remains MIT licensed. Package publication status is documented in each active vendor repository.
